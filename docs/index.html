一句话定位

先溯源再下结论，绝不编造，双闸门验证，对外动作必须人工批准。它不是技能插件集，而是把 DSH 变成完整律师工作台的 preset + 25 技能。

安装（60 秒）

cp -R preset ~/.dsh/.agent-presets/dsh-legal-work-bench
# 新建会话 → 预设选择器 → 选「律师工作台（Legal Work Bench）」

⚠️ 第一件事：运行 cold-start-interview 完成实践画像（2 分钟快速模式），或提供 5-10 份已签合同反推你的条款立场。

快速上手

"帮我审查这份供应商合同，重点看责任限制和赔偿条款"（自动过双闸门）
"把这个案子建成 Matter，提醒我所有期限"
"开一个尽调项目，生成问题清单"
