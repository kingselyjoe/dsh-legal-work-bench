# dsh-legal-work-bench 商业化说明

> 开源版（MIT）vs 付费版分界设计 ｜ 2026-08-17

## 一、原则

skills 是文本资产，无法靠"锁代码"区分（与 dsh-legal-ip 相同），因此采用**开放核心 + 资产/服务付费**：

- **开源版**：24 个技能全开放（MIT），获客 + 占生态位 + 建信任
- **付费版**：在开源版之上叠加付费资产（模板库/数据直连/体验增强）

## 二、开源版（GitHub，MIT）

| 内容 | 说明 |
|---|---|
| preset + 24 技能 | 画像/13 领域/双闸门/审计链/案件管理/内容联动 |
| 本地数据 | 画像、案件、审计全部本机 |
| 使用限制 | 无（个人/律所内部可自由用） |

## 三、付费层（不在本仓库，商业许可分发）

| 层 | 内容 | 为什么锁得住 |
|---|---|---|
| **案件管理 Pro** | 看板 UI、批量期限、团队协作、案件模板库（收案/策略/文书模板） | 模板与 UI 持续更新；团队功能需账号体系 |
| **权威法库直连** | 北大法宝 MCP 直连核验（04 事实核验自动查证） | 走你的后端代理，天然可控（key 服务端保管） |
| **内容生产联动** | 与 dsh-legal-ip Premium 的组合包（案件→内容素材管线） | 双产品组合，跨产品价值 |
| **团队/律所版** | 多律师协作、案件隔离权限、共享知识库、管理员审计面板 | 需要服务端与账号体系 |
| **垂类模板包** | 婚姻家事/劳动/知产/刑事等高频领域的一线模板与清单 | 持续更新的内容资产 |

## 四、定价参考（王律 ima 实证）

- 年费订阅（1 天 1 块钱量级 ≈ 365 元/年）+ 核心资产永久可用
- 律所版按席位/年；法库直连按调用量计费
- 参考：AI王律 ima 145 skills + 39 专家团，60 人订阅零退款——法律技能付费意愿已验证

## 五、合规

- 开源版 MIT；付费版商业许可（私有分发）
- 复用组件（dsh-law 等 MIT）保留版权声明；方法论参考 claude-for-legal-ZH（Apache 2.0）已在 LICENSE NOTICE 声明
- 法律执业合规：产品是辅助工具，最终责任在执业律师；不承诺结果

## 六、路线

```
v0.x 开源（24 技能全开放）→ 口碑与用户
  → 案件管理 Pro + 法库直连（第一批付费）
  → 团队版/律所版（第二批，服务端）
  → 与 dsh-legal-ip Premium 组合（生态收入）
```
