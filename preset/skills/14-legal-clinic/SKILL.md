# 法律诊所与公益咨询（legal-clinic）

## 功能

公益法律咨询辅助：接待登记、初步评估、材料整理、转介指引、回访记录。

## 前置条件

加载画像 `~/.dsh/legal-workbench/clinic/profile.md`；缺失则引导 00-cold-start-interview（记录诊所定位与服务边界）。

## 工作流

1. **接待登记**：咨询人基本信息（脱敏）、诉求类型（劳动/婚姻/合同/侵权/行政…）、紧急程度
2. **初步评估**：案情梳理 → 法律问题识别 → 初步法律评估（权利义务/可能路径）→ 明确"评估非正式意见"
3. **材料清单**：告知咨询人需补充的材料（合同/文书/证据）
4. **转介指引**：超出公益服务范围（诉讼代理/复杂案件）→ 转介执业律师/法律援助机构
5. **记录与回访**：接待记录（脱敏）、回访安排、案件跟踪（对接 docket-watcher 期限）

## 输出格式

```markdown
# 公益咨询记录：<编号>（脱敏）
## 一、诉求与案情（时间线）
## 二、初步评估（非正式意见）
## 三、材料清单
## 四、转介/跟进安排
```

## 核心规则

1. **边界明确**：公益咨询仅提供初步评估，不做正式法律意见、不承诺结果、不代理诉讼（转介）
2. **脱敏强制**：咨询人姓名/联系方式/身份证号脱敏存储
3. 涉诉时效/期限提醒（转介前提示）
4. 引用带来源（简明，避免过度法言法语）

## 本技能不做什么

- 不提供正式法律意见
- 不承接诉讼代理
- 不泄露咨询人信息

## 质量检查

- [ ] 评估边界声明清楚
- [ ] 转介指引明确
- [ ] 记录已脱敏
