# 内容联动（content-bridge）

## 功能

打通 work-bench（办案）与 dsh-legal-ip（内容）的桥梁：**办案产出 → 内容素材**（脱敏）、**热点 → 案源线索**。这是"两包一核"矩阵的联动机制。

## 联动一：办案产出 → 内容素材

案件办理中产生的高质量内容（研究笔记、案例解析、新规解读、风险提示），经**脱敏**后进入 dsh-legal-ip 素材库：

```
matters/<案件ID>/04_法律检索/*.md
        ↓ content-bridge 加工
  1. 脱敏：删除当事人姓名/金额/主体/案号（保留法律要点）
  2. 提炼：法律知识点 + 引用来源（法条/案例保留）
  3. 标注：内容类型（普法/新规/案例解析/风险提示）
  4. 输出：content/素材库/<类型>/<标题>.md（含来源标注）
        ↓
  dsh-legal-ip 的 02 选题/06 写作直接引用
```

## 联动二：热点 → 案源线索

dsh-legal-ip 的 01 热点监测产出 → work-bench 识别潜在案源：

```
法律热点（劳动仲裁/股权纠纷/婚恋财产/消费维权...）
        ↓
  → 匹配律师画像领域（00-cold-start-interview 的执业领域）
  → 标注案源线索（潜在咨询/潜在案件类型）
  → 写入 22-legal-matter 的咨询登记（14-legal-clinic 接待流程）
```

## 输出格式（素材条目）

```markdown
# 素材：<标题>
- 来源案件: m-XXXX（已脱敏）
- 内容类型: 普法/新规/案例解析/风险提示
- 法律要点: <核心知识点，逐条带来源>
- 引用: <法条/案例 + 来源>
- 脱敏声明: 已删除当事人/金额/主体信息
- 可发布: 是/需人工确认（敏感内容）
```

## 执行规则

1. **脱敏强制**：当事人姓名、身份证号、金额、主体名称、案号一律删除或替换；脱敏后必须自查
2. **敏感升级**：涉及在办案件、未决案件、名誉权风险的素材，标记"需人工确认"，不得直接进发布流程
3. **来源保留**：法律知识点来源（法条/案例）保留，供 dsh-legal-ip 核验
4. **双向闭环**：内容生产反馈的读者问题 → 可转回 work-bench 研究（形成知识循环）
5. **合规**：素材发布仍走 dsh-legal-ip 的双闸门（08 事实核验 + 09 合规审查）

## 本技能不做什么

- 不自动发布素材（走 dsh-legal-ip 流程）
- 不把未脱敏案件信息转入内容侧
- 不替用户判断敏感内容（人工确认）

## 质量检查

- [ ] 脱敏完整（无姓名/金额/主体/案号残留）
- [ ] 法律要点带来源
- [ ] 敏感内容已标记人工确认
- [ ] 素材落盘规范
