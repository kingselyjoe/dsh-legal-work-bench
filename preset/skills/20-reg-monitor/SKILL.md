# 监管动态监控（reg-monitor）

## 功能

监管动态跟踪：按行业/领域检索最新法规/政策/监管动态 → 筛选与本所/客户相关 → 生成新规速报与影响分析。

## 工作流

1. **监控范围**：行业（金融/医疗/互联网/制造…）+ 法律层级（法律/行政法规/部门规章/司法解释/监管动态）
2. **动态检索**：官方来源（国务院/部委/两高/监管机构官网）检索近 N 天新规（对接 03-legal-research 数据源）
3. **相关性筛选**：与本所业务/客户清单相关的动态（按画像领域过滤）
4. **影响分析**：新规要点 → 对客户业务/合同/合规的影响 → 待办建议
5. **速报生成**：周期速报（周报/月报）或即时快讯
6. **联动**：与 dsh-legal-ip 的 01 热点监测互通（法律新规 = 内容素材）

## 输出格式

```markdown
# 监管动态速报：<周期>（<行业>）
| 动态 | 发布机关 | 施行日期 | 要点 | 相关性 | 影响 |
|---|---|---|---|---|---|
| ... | ... | ... | ... | 高/中/低 | ... |
```

## 核心规则

1. 只引用官方来源（官网原文/权威发布），不采信二手解读
2. 施行日期/生效状态必须核验（新法替代旧法）
3. 影响分析标注"待核验/需人工确认"
4. 速报内容可复用为 dsh-legal-ip 的内容素材（脱敏后）

## 本技能不做什么

- 不自动对外发布速报（人批）
- 不替代对政策解读的官方口径

## 质量检查

- [ ] 官方来源引用
- [ ] 施行日期核验
- [ ] 相关性筛选正确
