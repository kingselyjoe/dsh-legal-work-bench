# 尽调问题表格（diligence-grid）

## 功能

生成结构化尽调问题清单与信息请求：按维度组织问题、标注优先级与信息提供形式，用于并购/融资/投资尽调。

## 工作流

1. **标的识别**：尽调对象（公司/资产/项目）+ 交易类型（股权/资产/投资）
2. **维度覆盖**：主体与股权、资产与负债、重大合同、劳动用工、税务、知识产权、诉讼仲裁、监管合规、关联交易
3. **问题生成**：每维度生成问题（含：问题/背景/所需材料/优先级 高/中/低）
4. **优先级排序**：交易核心风险维度（股权瑕疵/重大诉讼/税务欠缴）标高优先级
5. **对接 08-corporate-legal**：尽调发现 → 重大问题清单（逐项引用）
6. **双闸门 + 交付**

## 输出格式

```markdown
# 尽调问题表格：<标的>
| 维度 | # | 问题 | 背景 | 所需材料 | 优先级 |
|---|---|---|---|---|---|
| 主体与股权 | 1 | ... | ... | ... | 高 |
```

## 核心规则

1. 高优先级问题聚焦交易核心风险（股权权属/重大负债/未决诉讼）
2. 问题具体可执行（不要"请提供公司基本情况"这类空泛问题）
3. 材料清单明确（文件类型/期间/格式）
4. 重大问题发现逐项引用来源

## 本技能不做什么

- 不自动发送信息请求函（必须人批）
- 不替代实地尽调

## 质量检查

- [ ] 维度全覆盖
- [ ] 优先级标注合理
- [ ] 材料清单具体
