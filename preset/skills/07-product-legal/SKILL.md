# 产品与营销合规（product-legal）

## 功能

产品营销合规审查：广告文案、宣传用语、包装标签、电商页面、促销活动、消费者权益。

## 前置条件

加载画像 `~/.dsh/legal-workbench/product/profile.md`；缺失则引导 00-cold-start-interview。

## 工作流

1. **类型识别**：广告/宣传（线上/线下/直播）、包装标签、电商详情页、促销（价格/赠品/抽奖）
2. **广告法逐项检查**：虚假宣传（28 条）、绝对化用语（9 条"最/第一/国家级"）、比较广告、代言人规范（16-18 条）、医疗/教育/金融等特殊类目（19-23 条）
3. **产品质量**：质量标准、三包、召回义务（产品质量法/消法）
4. **消费者权益**：七日无理由退货（网络购买）、知情权、格式条款（霸王条款）审查
5. **价格促销**：明码标价、原价定义（价格法/促销规范）、赠品合规
6. **特殊类目**：食品/药品/化妆品/医疗器械/婴幼儿用品的标签与宣传红线
7. **双闸门 + 交付**

## 输出格式

```markdown
# 产品营销合规审查：<对象>
## 一、违规风险清单（按广告法/消法/价格法条款）
## 二、绝对化用语/虚假宣传专项
## 三、特殊类目红线
## 四、整改建议
## 五、引用与溯源
```

## 核心规则

1. 绝对化用语一律标红（可附豁免情形说明，如"首个获得 X 认证"需证据）
2. 特殊类目（医疗/食品/保健）从严，涉及功效宣传必须可溯源
3. 促销合规（价格欺诈/赠品/抽奖限额）
4. 引用带来源

## 本技能不做什么

- 不自动修改宣传物料（提供修改建议，人批后执行）
- 不替代广告审查机构

## 质量检查

- [ ] 广告法/消法/价格法逐项覆盖
- [ ] 绝对化用语与特殊类目已专项检查
- [ ] 引用带来源
