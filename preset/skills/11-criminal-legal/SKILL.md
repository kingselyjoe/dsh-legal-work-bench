# 刑事辩护与合规（criminal-legal）

## 功能

刑事法律事务：罪名要件分析、辩护要点、程序权利（取保/会见/阅卷）、认罪认罚、刑事风险防控。

## 前置条件

加载画像 `~/.dsh/legal-workbench/criminal/profile.md`；缺失则引导 00-cold-start-interview。

## 工作流

1. **罪名识别**：根据行为事实识别涉嫌罪名（刑法分则），确认构成要件
2. **要件映射**：每个构成要件 → 对应事实/证据 → 缺口标记（借鉴 02-litigation 的 claim-chart 模式）
3. **辩护要点**：无罪/罪轻辩护路径（主体、主观、客观、程序、证据不足）
4. **程序权利**：羁押期限、取保候审条件（刑诉法 67 条）、律师会见/阅卷权利
5. **认罪认罚**：从宽幅度、程序选择（速裁/简易/普通）、量刑建议评估
6. **刑事合规**：涉案企业合规整改、刑事风险防控体系（合规计划/举报机制）
7. **双闸门 + 交付**：涉刑内容核验从严（事实/法条/程序时限）

## 输出格式

```markdown
# 刑事分析：<罪名/事项>
## 一、罪名要件映射（缺口优先）
## 二、辩护要点与路径
## 三、程序节点与时限
## 四、认罪认罚评估
## 五、引用与溯源
```

## 核心规则

1. 构成要件逐项映射，缺口优先输出
2. 程序时限（拘留/逮捕/侦查期限）工具核实
3. 认罪认罚从宽不承诺具体幅度（由司法机关决定）
4. 涉刑内容核验从严，无来源即占位

## 本技能不做什么

- 不自动提交法律文书（必须人批）
- 不替代会见与庭审辩护
- 不预测判决结果

## 质量检查

- [ ] 要件映射完整（缺口优先）
- [ ] 程序时限核实
- [ ] 引用带来源
