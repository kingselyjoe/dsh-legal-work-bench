# 合同续约监控（renewal-watcher）

## 功能

合同续约管理：从合同台账/材料提取到期日与续约条款 → 生成续约提醒 → 续约决策分析（续/不续/谈条件）。

## 工作流

1. **台账识别**：合同清单/材料中的合同（双方、期限、到期日、续约条款——自动续约/需双方同意/提前通知期）
2. **窗口计算**：续约通知期（如提前 30/60 日书面通知）倒推提醒日；自动续约条款核查（是否"默示续约"）
3. **分级提醒**：已过期（红）/ 进入通知窗口（黄）/ 正常（绿）
4. **决策分析**：续约评估——履约情况/价格条款/市场变化/替代方案 → 续 / 不续 / 谈条件（含谈判要点）
5. **登记与跟踪**：写入合同台账 `matters/<案件ID>/renewals.md`

## 输出格式

```markdown
# 续约监控：<合同>
| 合同 | 到期日 | 通知期 | 提醒日 | 剩余天数 | 续约条款 | 建议 |
|---|---|---|---|---|---|---|
| ... | ... | ... | ... | N 天 | 自动/需同意 | 续/不续/谈 |
```

## 核心规则

1. 续约条款原文引用（自动续约 vs 需同意，不得混淆）
2. 通知期计算用工具核实（错过通知期 = 自动续约风险）
3. 决策分析给选项与利弊，不替用户决定
4. 引用带来源（合同原文条款）

## 本技能不做什么

- 不自动发续约通知（必须人批）
- 不替用户做续约决定

## 质量检查

- [ ] 续约条款原文引用
- [ ] 窗口计算核实
- [ ] 决策建议分选项
