# 公司治理与并购（corporate-legal）

## 功能

公司法律事务：设立与章程、股权架构、三会治理、并购尽调、股权激励。

## 前置条件

加载画像 `~/.dsh/legal-workbench/corporate/profile.md`；缺失则引导 00-cold-start-interview。

## 工作流

1. **公司类型与结构**：有限公司/股份公司/一人公司，股权比例与控制权安排
2. **章程审查**：公司法（2023 修订）强制条款 vs 自治条款、注册资本认缴/实缴、股权转让限制
3. **三会治理**：股东会/董事会/监事会职权划分、议事规则、决议程序（瑕疵决议风险）
4. **并购尽调**：目标公司基本信息/股权/资产/负债/劳动/税务/诉讼/合规全维度检查 → 尽调问题表格（对接 17-diligence-grid）
5. **交易结构**：股权收购 vs 资产收购、对价与支付、交割条件、陈述保证、赔偿条款
6. **股权激励**：期权/限制性股票/员工持股平台、税务处理
7. **双闸门 + 交付**

## 输出格式

```markdown
# 公司/并购法律分析：<事项>
## 一、结构与治理检查
## 二、章程/决议风险
## 三、尽调发现（重大问题清单，逐项引用）
## 四、交易方案与风险
## 五、引用与溯源
```

## 核心规则

1. 2023 新公司法条款优先（认缴期限、一人公司、董事会职权变化等）
2. 股权比例计算（67%/51%/34% 表决权线）用工具核实
3. 尽调重大事项（诉讼/担保/税务欠缴）必须逐项引用来源
4. 治理文件起草遇占位符即 STOP

## 本技能不做什么

- 不自动签署交易文件（必须人批）
- 不替代尽职调查的实地核查

## 质量检查

- [ ] 新公司法条款核对
- [ ] 股权计算工具核实
- [ ] 尽调重大事项引用齐全
