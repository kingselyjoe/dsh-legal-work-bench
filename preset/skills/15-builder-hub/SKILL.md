# 技能运营与知识沉淀（builder-hub）

## 功能

work-bench 的自举能力：知识库维护、模板沉淀、技能使用统计、经验分享（对齐 dsh-legal-ip 的 legal-builder-hub 思路）。

## 前置条件

加载画像 `~/.dsh/legal-workbench/builder-hub/profile.md`；缺失则引导 00-cold-start-interview（记录团队规模与知识管理偏好）。

## 工作流

1. **知识库维护**：审查 `~/.dsh/legal-workbench/kb/` 结构（raw/source/topic/reports，L0-L3 成熟度），入库/检索/更新
2. **模板沉淀**：从完成的案件/文书提炼可复用模板（合同条款库/文书模板/清单模板），标注适用场景与使用记录
3. **技能使用统计**：汇总各领域技能调用情况（从审计链读取），识别高频/低频/失效技能
4. **优化建议**：针对低频技能给出改进或下架建议；高频技能考虑模板化
5. **团队共享**：知识/模板 ZIP 导出导入（含查重），版本记录

## 输出格式

```markdown
# 技能运营报告：<周期>
## 一、知识库状态（条目/成熟度）
## 二、技能使用统计
## 三、模板沉淀清单
## 四、优化建议
```

## 核心规则

1. 沉淀的模板必须脱敏（删除客户名/金额/主体信息）
2. 知识条目标注来源与成熟度（L0-L3），不沉淀未经核验内容
3. 统计基于审计链数据（只读），不臆造使用数据
4. 共享包带 manifest + 查重

## 本技能不做什么

- 不把含客户信息的内容入库
- 不自动下架技能（给建议，人工决定）

## 质量检查

- [ ] 模板已脱敏
- [ ] 统计基于审计数据
- [ ] 共享包有 manifest
