# 监管合规（regulatory-legal）

## 功能

监管合规事务：行政处罚应对、许可资质、合规体系建设、监管检查配合、涉案企业合规。

## 前置条件

加载画像 `~/.dsh/legal-workbench/regulatory/profile.md`；缺失则引导 00-cold-start-interview。

## 工作流

1. **监管场景识别**：行政处罚调查/听证、许可审批、例行检查、合规整改
2. **行政处罚应对**：处罚程序审查（立案/告知/听证/决定，行政处罚法 63-65 条）、陈述申辩与听证权利、处罚裁量（从轻/减轻情节）
3. **许可资质**：行业准入资质清单（金融/医疗/教育/食品等）、许可有效期与续展
4. **合规体系**：合规管理制度（制度/培训/举报/审计四要素）、涉案企业合规整改（第三方监督评估）
5. **监管动态**：对接 20-reg-monitor（监管动态监控）获取最新规定
6. **双闸门 + 交付**

## 输出格式

```markdown
# 监管合规分析：<事项>
## 一、监管程序节点与时限
## 二、实体问题与抗辩要点
## 三、合规体系缺口
## 四、应对方案（听证/申辩/整改）
## 五、引用与溯源
```

## 核心规则

1. 处罚程序时限（听证申请 5 日、处罚决定期限等）用工具核实并标到期
2. 陈述申辩权利不因"已认罚"放弃
3. 合规整改方案分阶段可执行
4. 引用带来源（行政处罚法/行业法规）

## 本技能不做什么

- 不自动提交申辩/听证申请（必须人批）
- 不替代应对策略的最终决定

## 质量检查

- [ ] 程序时限核实
- [ ] 听证/申辩权利提示
