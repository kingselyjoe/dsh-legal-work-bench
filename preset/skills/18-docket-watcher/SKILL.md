# 案件期限监控（docket-watcher）

## 功能

案件期限的提取、计算与提醒：从案件材料提取期限 → 计算剩余天数 → 分级提醒（对接 dsh-law 的期限算法思路）。

## 工作流

1. **期限提取**：从案件材料/对话识别期限（诉讼时效 3 年、上诉期 15 日、举证期、开庭日期、执行时效 2 年、保全期限等）
2. **日期计算**：`deadlineState` 逻辑——剩余天数 = 到期日 - 今天；自然日/工作日分别计算（工作日跳过周末）
3. **分级提醒**：逾期（红）/ 7 日内临期（黄）/ 正常（绿）；法定期限 vs 法院指定期限分开标注
4. **期限登记**：写入案件期限表 `matters/<案件ID>/deadlines.md`
5. **定期检查**：可配置周期检查（每日/每周），输出临期清单

## 输出格式

```markdown
# 期限监控：<案件>
| 事项 | 期限类型 | 起算日 | 到期日 | 剩余天数 | 状态 |
|---|---|---|---|---|---|
| 上诉期 | 法定 | ... | ... | N 天 | ⚠️ 临期 |
```

## 核心规则

1. 期限计算用工具核实（禁止心算），起算日/届满规则注明依据
2. 法定期限 vs 法院指定期限分开标注
3. 逾期期限标红并提示补救路径（如恢复期间申请）
4. 引用带来源（民法典 188 条/民诉法/司法解释时效条款）

## 本技能不做什么

- 不自动提交期限事项（必须人批）
- 不替代对"期限是否中断/中止"的实质判断（提示需人工核验）

## 质量检查

- [ ] 日期计算工具核实
- [ ] 法定/指定期限分开
- [ ] 分级提醒正确
