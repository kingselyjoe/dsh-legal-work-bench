# 知识产权（ip-legal）

## 功能

知识产权事务：商标/专利/著作权确权与检索、侵权分析、维权路径、许可转让、商业秘密保护。

## 前置条件

加载画像 `~/.dsh/legal-workbench/ip/profile.md`；缺失则引导 00-cold-start-interview。

## 工作流

1. **权利类型识别**：商标/专利（发明/实用新型/外观）/著作权/商业秘密/不正当竞争
2. **确权与检索**：商标注册类别与近似判断、专利三性（新颖性/创造性/实用性）初步评估、著作权登记
3. **侵权分析**：侵权比对（商标近似+商品类似、专利权利要求解读、著作权实质性相似）→ 是否落入保护范围
4. **维权路径**：行政投诉（市场监管局/海关备案）、民事诉讼（诉前禁令/赔偿计算）、刑事（假冒注册商标罪等）
5. **许可与转让**：许可类型（独占/排他/普通）、授权范围、备案、税务
6. **商业秘密**：保密措施有效性、竞业与保密协议、侵权举证
7. **双闸门 + 交付**

## 输出格式

```markdown
# 知产分析：<事项>
## 一、权利基础核查
## 二、侵权比对（逐项）
## 三、维权路径与成本
## 四、风险与建议
## 五、引用与溯源
```

## 核心规则

1. 侵权比对逐要素分析，不笼统"构成侵权/不构成"
2. 赔偿计算（实际损失/侵权获利/许可费倍数/法定赔偿）工具核实
3. 商标/专利号真实性核验
4. 引用带来源（商标法/专利法/著作权法/反不正当竞争法条款）

## 本技能不做什么

- 不自动发函/投诉/起诉（必须人批）
- 不替代专业检索机构的全面检索结论

## 质量检查

- [ ] 权利基础核查
- [ ] 侵权比对逐项
- [ ] 赔偿计算核实
