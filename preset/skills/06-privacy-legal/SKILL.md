# 数据合规与隐私（privacy-legal）

## 功能

数据合规审查与咨询：个人信息处理合规、隐私政策/告知同意、敏感个人信息、跨境传输、数据安全评估。

## 前置条件

加载画像 `~/.dsh/legal-workbench/privacy/profile.md`；缺失则引导运行 00-cold-start-interview。

## 工作流

1. **场景识别**：个人信息处理场景（收集/存储/使用/加工/传输/提供/公开/删除）+ 主体类型（处理者/受托处理者）
2. **合法性基础核对**：同意 / 合同必需 / 法定义务 / 紧急情况 / 已公开信息等（个保法 13 条）
3. **告知-同意检查**：告知内容完整（处理者/目的/方式/种类/保存期限/权利）、单独同意场景（敏感信息/跨境/向第三方提供）
4. **敏感个人信息专项**：生物识别/医疗健康/金融账户/行踪轨迹等（28 条），单独同意 + 必要性评估
5. **跨境传输**：安全评估 / 标准合同 / 认证（38-40 条）路径选择
6. **合规制度**：隐私政策、内部管理制度、安全事件应急预案、影响评估（PIA）
7. **双闸门 + 交付**：事实核验（04）+ 合规审查（05）通过后交付

## 输出格式

```markdown
# 数据合规审查：<事项>
## 一、处理场景与合法性基础
## 二、合规缺口清单（按个保法/数安法/网安法条款）
## 三、敏感信息/跨境专项
## 四、整改建议（按优先级）
## 五、引用与溯源
```

## 核心规则

1. 合法性基础不齐全即标记缺口，不默认"有同意就合规"
2. 跨境传输路径必须明确（评估/标准合同/认证三选一）
3. 敏感个人信息从严（单独同意 + 必要性）
4. 引用带来源（个保法条款 + 官方解读）

## 本技能不做什么

- 不自动发送隐私政策/整改文件（必须人批）
- 不替代监管申报

## 质量检查

- [ ] 处理场景全覆盖
- [ ] 敏感/跨境专项已查
- [ ] 引用带来源
