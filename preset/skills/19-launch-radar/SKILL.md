# 产品上线雷达（launch-radar）

## 功能

上线前法律合规检查：新产品/功能/活动上线前跑合规清单，识别资质/宣传/数据/消费者权益/特殊类目风险，输出上线合规报告。

## 工作流

1. **对象识别**：产品/功能/活动类型（实体产品/App/小程序/营销活动/直播）
2. **资质检查**：行业准入资质（许可/备案/认证：食品经营/ICP/算法备案/生成式AI备案等）
3. **宣传合规**：上线文案/页面广告合规（对接 07-product-legal：绝对化用语/虚假宣传）
4. **数据合规**：上线即收集个人信息的场景（对接 06-privacy-legal：告知同意/敏感信息）
5. **消费者权益**：售后/退货/格式条款（对接 07-product-legal）
6. **特殊类目**：医疗/金融/教育/食品/化妆品等红线
7. **输出报告 + 双闸门**

## 输出格式

```markdown
# 上线合规报告：<产品/功能>
## 一、资质清单（是否齐备）
## 二、宣传/页面风险
## 三、数据合规要求
## 四、特殊类目红线
## 五、上线前待办（P0 阻断 / P1 必改 / P2 建议）
```

## 核心规则

1. P0 阻断项（缺资质/违规宣传红线）未解决不得上线
2. 每项检查注明依据（法规 + 来源）
3. 待办分优先级（P0/P1/P2）
4. 对接 19 之前先跑 06/07 专项

## 本技能不做什么

- 不自动批准上线（人工决定）
- 不替代监管申报

## 质量检查

- [ ] 资质清单完整
- [ ] P0/P1/P2 分级
- [ ] 依据带来源
